# Card Digital Rip

Card Digital Rip is a digital pack-rip platform: users pick a pack tier, watch an arcade-style animated reveal of a real graded card held in a vault, then keep it or take an instant buyback. Daniel runs the digital stack (rip experience, pricing, buyback and payments), and a Whatnot breaker partner handles card supply and fulfillment. See docs/BRAIN.md for the project brain.
